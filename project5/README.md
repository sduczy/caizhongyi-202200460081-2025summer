# SM2签名算法误用攻击验证项目

## 项目概述

本项目实现了SM2椭圆曲线数字签名算法中常见误用场景的POC验证，包括：

1. **随机数重用攻击** - 演示使用相同随机数k签名不同消息时的私钥泄露
2. **可预测随机数攻击** - 演示随机数k可预测时的私钥恢复
3. **签名验证绕过攻击** - 演示构造特殊签名绕过验证机制
4. **私钥恢复攻击** - 演示通过多个签名样本恢复私钥

## 攻击方法详解

### 随机数重用攻击

**原理**: 当使用相同的随机数k对两个不同消息进行签名时，攻击者可以通过数学关系恢复私钥。

**数学推导**:
```
签名1: s₁ = k⁻¹ × (e₁ + d × r) mod n
签名2: s₂ = k⁻¹ × (e₂ + d × r) mod n

私钥恢复: d = (s₁ × h₂ - s₂ × h₁) / (r × (s₁ - s₂)) mod n
```

**成功率**: 100%（当k重用时）

### 可预测随机数攻击

**原理**: 当随机数k可以通过某种方式预测时，攻击者可以直接从签名中计算私钥。

**数学推导**:
```
已知: s = k⁻¹ × (e + d × r) mod n
因此: d = (k × s - e) × r⁻¹ mod n
```

**成功率**: 100%（当k可预测时）

### 签名验证绕过攻击

**原理**: 通过构造特殊的签名值，尝试绕过签名验证机制。

**攻击方法**:
- r = 0 的无效签名
- s = 0 的无效签名
- 格式错误的签名

### 私钥恢复攻击

**原理**: 通过收集多个签名样本，利用统计分析或数学关系恢复私钥。

**复杂度**: O(2^128) 到 O(2^256)，取决于随机数生成器的质量。

## 安全建议

1. **随机数管理**
   - 每次签名必须使用唯一的随机数k
   - 随机数k必须具有足够的熵值，不可预测
   - 使用密码学安全的随机数生成器

2. **签名验证**
   - 实现严格的签名验证，拒绝无效签名
   - 验证r和s的有效性
   - 确保r, s ∈ [1, n-1]

3. **密钥管理**
   - 定期更换密钥对
   - 安全存储私钥
   - 限制私钥的访问权限

## 技术细节

### SM2参数

- **椭圆曲线**: y² = x³ + ax + b (mod p)
- **基点G**: 椭圆曲线上的生成点
- **阶n**: 基点G的阶
- **私钥d**: 随机选择的整数，1 ≤ d < n
- **公钥Q**: Q = d × G

### 签名格式

SM2签名采用(r, s)格式，其中：
- r = x₁ mod n (x₁为点R = k × G的x坐标)
- s = k⁻¹ × (e + d × r) mod n
